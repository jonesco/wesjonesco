Flatbed for macOS

Support

Need help with Flatbed? Email wes@jonesco.com. Please include your macOS version, your Flatbed version, and a short description of what happened.

Back up your work

Choose File → Export Backup… to save your issues as JSON. Choose File → Import Backup… to replace the current issue list with a backup.

iCloud sync

Flatbed uses your private iCloud database when iCloud is available. Make sure you are signed in to the same Apple Account on each Mac and that iCloud Drive is enabled. If iCloud is temporarily unavailable, Flatbed continues to keep your work locally.

Privacy

Flatbed has no advertising, analytics, tracking, or developer-operated server. Read the complete Flatbed Privacy Policy.
